# Hej og velkommen 👋

Jeg er uddannet **IT-supporter** (Data og Kommunikation, TEC Ballerup) og bor i Storkøbenhavn.
Jeg kan lide at få ting til at virke – og at forstå, hvorfor de virker.

## Hvad jeg arbejder med
- **IT-support:** 1. og 2. linje, Windows, brugere, fejlfinding på PC og mobil
- **Netværk:** pfSense-firewall, VLAN, managed switches, VPN og Tailscale
- **Homelab:** Proxmox med virtuelle maskiner og containere, Pi-hole, Jellyfin, n8n
- **AI og automatisering:** lokale sprogmodeller med Ollama og OpenWebUI, AI-agenter
- **Lidt kode:** Python og SQL
